# AT-Modem Emulator

Эмулятор AT-модема на C++20 для Linux.  
~90 строк кода, без внешних зависимостей.

## Сборка

```bash
make            # → бинарник modem
```

## Запуск

Нужна пара виртуальных serial-портов. Проще всего через `socat`:

```bash
# Терминал 1 — создаём пару связанных PTY
socat -d -d pty,raw,echo=0 pty,raw,echo=0
# socat напишет что-то вроде:
#   ... PTY is /dev/pts/3
#   ... PTY is /dev/pts/4
```

```bash
# Терминал 2 — запускаем эмулятор на одном конце
./modem /dev/pts/3 dict.txt
```

```bash
# Терминал 3 — подключаемся к другому концу как «клиент»
picocom /dev/pts/4
# или: screen /dev/pts/4
# или: minicom -D /dev/pts/4
```

Теперь в picocom набираем `AT` + Enter — модем отвечает `OK`.

## Поддерживаемые команды (dict.txt)

| Команда     | Ответ                              |
|-------------|------------------------------------|
| `AT`        | `OK`                               |
| `ATE0`      | `OK` (выключает эхо)              |
| `ATE1`      | `OK` (включает эхо)               |
| `ATI`       | `Modem Emulator v1.0`             |
| `AT+COPS`   | `+COPS: (2,"MTS","MTS","25001")`  |
| `AT+CPIN?`  | `+CPIN: READY`                    |
| `AT+CSQ`    | `+CSQ: 18,99`                     |

Новые команды добавляются одной строкой в `dict.txt`.

## Паттерны в словаре

| Символ  | Значение                          |
|---------|-----------------------------------|
| `*`     | Ноль или любая цепочка символов   |
| `.`     | Любой один символ                 |
| `[abc]` | Один из символов в скобках        |
| Буквы   | Сравниваются регистронезависимо   |

Пример: `ATE[01]` — матчит и `ATE0`, и `ATE1`.

## Архитектура (для собеседования)

```
modem.cpp  (один файл, ~90 строк)
├── is_match()   — рекурсивный glob-матчер
├── load_dict()  — чтение словаря из файла
└── main()       — TTY raw-mode + цикл чтения
```
