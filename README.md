## Сборка

```bash
g++ -std=c++17 -O2 -Wall -o modem main.cpp
```

## Запуск

```bash
./modem <tty-устройство> <файл-правил>
./modem /dev/pts/3 rules.txt      # явные аргументы
./modem                            # по умолчанию: /dev/pts/2  rules.txt
```

## Проверка через socat

### Шаг 1 — Создать пару виртуальных COM-портов

```bash
socat -d -d pty,raw,echo=0 pty,raw,echo=0
```

socat выведет две строки вида:

```
... PTY is /dev/pts/3
... PTY is /dev/pts/4
```

### Шаг 2 — Запустить эмулятор на первом порту

```bash
./modem /dev/pts/3 rules.txt
```

### Шаг 3 — Подключиться ко второму порту (любой вариант)

**Вариант A — microcom / picocom:**

```bash
microcom -s 115200 /dev/pts/4
# или
picocom -b 115200 /dev/pts/4
```

Набирайте команды и нажимайте Enter:

```
AT        →  OK
ATI       →  Modem_Emulator
              OK
ATE0      →  OK
AT+CPIN?  →  +CPIN: READY
              OK
BLAH      →  ERROR
```

**Вариант B — проверка через echo (быстрый тест):**

```bash
# Отправить команду AT и прочитать ответ
echo -ne "AT\r" > /dev/pts/4 && cat /dev/pts/4
```

> **Примечание:** `cat` будет ждать данных бесконечно. Нажмите `Ctrl+C` после получения ответа.

## Формат rules.txt

```
# Комментарии начинаются с #
# Формат: шаблон=ответ

AT=OK
ATE[1,0]=OK
ATI=Modem_Emulator\r\nOK
AT+COPS*=OK
AT+CPIN?=+CPIN: READY\r\nOK
AT+CPIN*=OK
```

### Синтаксис шаблонов

| Символ  | Значение                              |
|---------|---------------------------------------|
| `*`     | Ноль или более любых символов         |
| `.`     | Ровно один любой символ               |
| `[abc]` | Один из перечисленных символов        |
| Буквы   | Сравниваются без учёта регистра       |

### Спецсимволы в ответах

| Запись | Результат        |
|--------|------------------|
| `\r`   | Символ CR (0x0D) |
| `\n`   | Символ LF (0x0A) |

## Архитектура

```
main.cpp  (~120 строк)
├── unescape()     — замена \r\n в ответах на реальные CR/LF
├── load_rules()   — чтение правил из файла
├── is_match()     — рекурсивный матчер шаблонов
├── setup_tty()    — настройка TTY: raw-режим, 115200 8N1
└── main()         — цикл: read → match → write
```

## Ключевые флаги termios

| Флаг        | Зачем                                       |
|-------------|---------------------------------------------|
| `O_NOCTTY`  | Не назначать TTY управляющим терминалом      |
| `CS8`       | 8 бит данных                                |
| `CREAD`     | Включить приёмник                           |
| `CLOCAL`    | Игнорировать линии управления модемом        |
| `~ICANON`   | Отключить каноническую (построчную) обработку|
| `~ECHO`     | Отключить эхо                               |
| `~ISIG`     | Отключить обработку сигналов (Ctrl+C и т.д.) |
| `VMIN=1`    | Блокировать read() до получения ≥1 байта     |
| `B115200`   | Скорость 115200 бод                         |
